# Homelab Assets

Static images used by my homelab services.

## Structure

- `avatars/` — avatars
- `icons/` — service icons
- `logos/` — logos

## Usage

Raw URL format:

`https://raw.githubusercontent.com/<OWNER>/homelab-assets/main/<PATH>`

## Notes

- Public repository.
- Use descriptive filenames.
- Do not store secrets.
